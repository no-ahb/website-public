Two coordinates.
Twenty-four parameters.

For experiments with Maya Beiser's Don't Look Bach material, I explored a way to move through mixes by example. A position on an XY pad is paired with a set of mix values. FluCoMa learns the relationship, so a small gesture can change many parameters together.

Designing a smaller control surface

The original patch stores two parallel datasets, xydata and mixparams. It turns a collection of preferred mixes into a continuous control space. The saved network uses sigmoid activations, keeping its outputs between zero and one.

Keeping change slow enough to hear

A later mixing patch generates new target positions and interpolates toward them. Separate controls set how often a target changes and how long the transition takes. Their relationship determines whether a mix settles or stays in motion.

Knowing when recognition is unreliable

A separate classifier compares timbre, pitch, and their combination. It omits the loudness-related first MFCC, tests predictions every 50 ms, and gates them below −30 dB. Notes in the patch describe the pitch and combined experiments as unreliable. The saved fit number is a training result, not a validated accuracy claim.

Original implementation and scope

Max and FluCoMa prototypes, 2022. This browser view evaluates the archived AI_test.json network from the four-mix experiment. It displays its normalized output vector; the original Ableton parameter bindings and cello recordings are not running here. The complete training set and final performance configuration have not been recovered, so this case presents the development work.
